# ECOGEST (EDUCOGEST) - Plateforme de Gestion Scolaire Bivalente

Système moderne de gestion scolaire bivalente (Primaire & Secondaire) adapté au programme béninois et sous-régional :
- **Primaire :** Évaluation par compétences fondamentales, bulletins trimestriels avec cotes et appréciations.
- **Secondaire :** Gestion par disciplines, coefficients, moyennes pondérées et délibérations du censeur.
- **Modules intégrés :** Gestion financière et scolarité, messagerie, emplois du temps, espaces dédiés (Directeur, Censeur, Enseignant, Parent, Support).

## Démarrage rapide

```bash
# Installation des dépendances
npm install

# Lancement du serveur de développement local
npm run dev
```

L'application est accessible sur [http://localhost:3000](http://localhost:3000).
